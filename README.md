# Building and running instructions

1. Import the project folder into your IDE.
2. Make sure that all provided .java files are under src.
3. Locate the "Main.java" file and double-click on it.
4. To run, right-click, find "Run As," and hover over it
5. When hovering over it will give you the option "1 Java Application"/"Java Application"; click it, and it will run.
